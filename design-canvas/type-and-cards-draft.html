The move worth stealing: a condensed face at regular weight, scaled up. Pragati Narrow at 80px/400 reads as loud as a grotesk at 700, but sets far more words per line — which is why their stat blocks and case titles fit without truncating. Radius, meanwhile, sits almost entirely on 8px and 4px, with 32px and 80px reserved for feature surfaces.

The case that was made for it — kept for the record. The condensed display gives long case-study titles room to breathe at large sizes — the exact problem the current Familjen Grotesk hero has, where two-clause headlines wrap to four lines. Archivo is a workhorse with a genuine 400–700 range and a variable width axis you can borrow later. The Instrument Serif quote is the one warm note in an otherwise industrial system, and it keeps testimonials from reading as body copy in a box. Risk: Pragati Narrow has a single 400 and 700 cut and a small character set — it will not carry CJK, so keep the Noto fallbacks in the body stack.

The loudest option — and the one that shipped. Bebas is caps-only, so the "sentence case strictly" rule in the old type spec no longer describes what renders. Four things had to change on the way in. One: weight dropped from 700 to 400 everywhere — Bebas has a single cut, and the site's markup pairs .font-display with .font-bold in about thirty places, which would have handed the browser a 700 to synthesise. A doubled-class guard in typography.css out-specifies it without touching a component. Two: tracking flipped from −0.03em to positive — condensed caps need opening up, not closing. Three: the display steps of the scale went up ~10%, because Bebas sets much narrower and headlines were under-filling their measure. Four: line-heights tightened (h1 to 0.88), since caps carry no descenders. Headings stay authored in sentence case so a failed webfont load degrades to Impact quietly instead of shouting the page.

Radius

Rounded corners, on a scale

smobler currently ships --radius-none: 0px and a pill — corners are either square or fully round, with nothing between. Lazarev's scale fills that gap. These are their exact steps; the last two are for feature surfaces only.

One rule that keeps a rounded system from going soft: nested radii step down by the padding between them. A 24px shell with 8px of padding takes a 16px well. Study 03 below is built that way; get it wrong and the inner corner reads as a mistake.

Cards

Six card studies

All six hover. Each pairs a radius step with a shadow model — the hard offset lift smobler already uses, or a soft ambient one. They don't mix: a rounded card with a hard 8px offset shadow reads as a sticker, a square card with a soft blur reads as unfinished. Pick one per surface.

What shipped: 01 and 06, at 12px. Every .card-lift-snow surface — about twenty across the site — now takes --radius-card: 12px, and image wells nested inside them take --radius-media: 8px, one step down for the padding between. Buttons and inputs take 8px, the person drawer 16px on its leading edge only, since it sits flush to the viewport. What did not ship, and why: studies 02–05 all pair a larger radius with the soft ambient shadow. That combination is a different design thesis from §3's "sunlight on snow" — the hard down-right offset reads as cast light against a tight corner and as a sticker against a soft one. Going rounder than 16px means giving up the directional shadow, which is a bigger call than a corner.

What landed for Option D

This is in styles/tokens.css and styles/typography.css now; next build passes. Originals are kept at design-canvas/_pre-option-d/ — this repo isn't under version control, so that copy is the only way back. The card studies above are not applied: no radius has been picked yet.

/* styles/typography.css — the @import */
@import url('https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Archivo:wght@400;500;600;700&family=Martian+Mono:wght@300;400;500;700&display=swap');

/* styles/tokens.css — font families */
--font-display: 'Bebas Neue', Impact, 'Haettenschweiler', 'Arial Narrow', sans-serif;
--font-body:    'Archivo', -apple-system, 'Segoe UI', 'Noto Sans SC', 'Noto Sans JP', sans-serif;
--font-mono:    'Martian Mono', ui-monospace, Consolas, monospace;  /* unchanged */

/* tracking runs positive now — condensed caps open up, they don't close */
--track-display: 0.005em;  --track-h1: 0.008em;
--track-h2: 0.012em;       --track-h3: 0.02em;

/* display steps up ~10%: Bebas sets narrower, headlines were under-filling */
--t-hero:    clamp(3rem, 9.6vw, 9rem);       /* was 2.75 / 9vw / 8.25 */
--t-display: clamp(3.5rem, 7.8vw, 7.5rem);
--t-h1:      clamp(2.75rem, 5vw, 4.5rem);
--t-h2:      clamp(1.875rem, 2.8vw, 2.75rem);
--t-h3:      1.375rem;

/* the guard: .font-bold is one class, so two beat it — no !important,
   no edits to the ~30 components that pair the two classes */
.font-display.font-display { font-weight: 400; letter-spacing: var(--track-h2); }

/* ── corners ───────────────────────────────────────────────────
   Semantic aliases over the raw scale, so a corner retunes in one
   place. 41 inline `borderRadius: 0` styles were removed first —
   inline wins over any class, so nothing would have rounded. */
--radius-card:    var(--radius-12);   /* every .card-lift-snow + .person-card */
--radius-media:   var(--radius-8);    /* .media-well, nested one step down */
--radius-control: var(--radius-8);    /* buttons, inputs, selects */
--radius-panel:   var(--radius-16);   /* drawers — leading edge only */

Two things to watch now that it's live. One: Bebas carries no CJK at all — any heading in those scripts falls straight through to the system sans, a much wider break than the old grotesk made. Body copy is safe; the Noto fallbacks are still in the stack. Two: headings must keep being authored in sentence case. The font draws caps by itself, so nothing is gained by an explicit text-transform, and if the webfont ever fails to load, Impact would shout the entire page instead of degrading quietly.
